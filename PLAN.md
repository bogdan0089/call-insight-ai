# AI-контроль якості дзвінків — план

**Що будуємо:** завантажив запис розмови → система розшифровує його в текст →
LLM перевіряє розмову по чеклісту → показує оцінку і **цитати-докази** з розмови.

**Навіщо:** це AI-версія ОКК, яким Bohdan займається на роботі. Там порушення
рахуються по сухих цифрах (паузи, тривалість), тут — **по змісту розмови**.

**Режим роботи:** Bohdan веде і думає, Claude пише код і пояснює «чому саме так».
«Стоп, зараз я пишу» — Claude зупиняється і перевіряє. Частину кроків Bohdan
робить руками навмисно, щоб перевірити локально й зрозуміти.

## Потік даних

```
телефонія (фейкова)  ──вебхук──►  POST /webhooks/telephony
                                        │  підпис, дедуп, 200 миттєво
завантаження вручну ──────────►  POST /calls (mp3)
                                        │
                                        ▼
                                   зберегли файл
                                   статус = queued
                                        │
                                        ▼
                                    RabbitMQ
                                        │
                                        ▼
                                 Celery-воркер
                                   │        │
                        Whisper ◄──┘        └──► LLM (чекліст)
                        текст+таймкоди           JSON: пункт → так/ні + цитата
                                   │        │
                                   └────┬───┘
                                        ▼
                                    Postgres
                                        │
                        ┌───────────────┼───────────────┐
                        ▼               ▼               ▼
                  GET /calls/{id}   бал і порушення   вихідний
                  (клієнт полить)   за правилами       вебхук
```

## Таблиці (чернетка, уточнюємо на етапі 1)

- `calls` — сам дзвінок: файл, тривалість, оператор, статус обробки
- `transcripts` — розшифровка цілком (важкий текст, окремо від `calls`)
- `transcript_segments` — репліки з таймкодами: хто, коли, що сказав
- `checklist_items` — пункти скрипта: формулювання, вага, обов'язковий чи ні
- `call_scores` — результат по кожному пункту: так/ні + цитата + впевненість
- `raw_ai_responses` — сирі відповіді Whisper і LLM у JSONB, окремою таблицею
